# Security

If you find a security problem in Radiate, for example a playlist, guide
or web page that can run code, read your provider passwords, or use the
local stream relay from outside your computer, please report it
privately:
[Security, Report a vulnerability](https://github.com/livexibot/Radiate/security/advisories/new).

Please do not open a public issue for it. You will get an answer there,
and a fix goes into the next release.

Only the latest release is supported.
